## 2. Three Logo Directions

### Concept 1: **Woven Monogram** — *Heritage Meets Modern*
**Visual Metaphor:** Single continuous thread forming S + F — the loom, the drape, the connection.

| Component | Spec |
|-----------|------|
| **Mark** | Interlocking S (vertical spine) + F (horizontal arms) as woven knot. Gradient peach→terracotta. White thread "weaves through" at crossings. |
| **Wordmark** | DM Sans Regular, 48pt, tracking +2. Charcoal `#2D2D2D`. |
| **Tagline** | DM Sans Light, 14pt, tracking +4, uppercase. Terracotta `#A65E4D`. |
| **Best For** | App icon, hang tags, embroidery, woven labels, social avatar. |
| **Feeling** | Tactile, artisanal, continuous, human. |

---

### Concept 2: **Flame Petal** — *Aspirational & Feminine*
**Visual Metaphor:** S + F unified into a single flame/petal form — glow, transformation, bloom.

| Component | Spec |
|-----------|------|
| **Mark** | Teardrop/flame silhouette. Positive shape = gradient sand→peach→gold. Negative space carves S (spine) + F (crossbar + stem). |
| **Wordmark** | Playfair Display Regular, 48pt, tracking +1.5. Charcoal `#2D2D2D`. |
| **Tagline** | DM Sans Regular, 13pt, tracking +3, uppercase. Peach `#C97B6B`. |
| **Best For** | Store signage, packaging foil, hero web, campaign key visual. |
| **Feeling** | Luminous, premium, emotional, celebratory. |

---

### Concept 3: **Minimal Geometric** — *Architectural & Confident*
**Visual Metaphor:** S as vertical column, F as horizontal beams — structure, foundation, cornerstone.

| Component | Spec |
|-----------|------|
| **Mark** | Two strokes: S (vertical, curved terminals) + F (two horizontals). Charcoal gradient. Two peach connection dots at junctions. |
| **Wordmark** | Space Grotesk Medium, 48pt, tracking 0. "A" letters highlighted in peach. |
| **Tagline** | Space Grotesk Light, 12pt, tracking +5, uppercase. Dark taupe `#4A3F3A`. |
| **Best For** | Digital UI, favicon, motion end-frame, store façade, business cards. |
| **Feeling** | Clean, modern, systematic, trustworthy. |

## 3. Color System

| Role | Hex | RGB | CMYK | Usage |
|------|-----|-----|------|-------|
| **Primary Peach** | `#C97B6B` | 201, 123, 107 | 0, 55, 60, 21 | Mark primary, CTAs, highlights |
| **Deep Terracotta** | `#A65E4D` | 166, 94, 77 | 0, 60, 68, 35 | Taglines, hover states, accents |
| **Warm Sand** | `#D4A574` | 212, 165, 116 | 0, 28, 45, 17 | Gradient mid, backgrounds |
| **Gold Accent** | `#E8B87D` | 232, 184, 125 | 0, 22, 46, 9 | Foil stamping, premium touches |
| **Charcoal** | `#2D2D2D` | 45, 45, 45 | 0, 0, 0, 82 | Wordmark, body text, UI |
| **Dark Taupe** | `#4A3F3A` | 74, 63, 58 | 0, 15, 22, 71 | Secondary text, borders |
| **Cream Base** | `#F5F0EB` | 245, 240, 235 | 0, 2, 4, 4 | Page backgrounds, packaging |
| **White** | `#FFFFFF` | 255, 255, 255 | 0, 0, 0, 0 | Negative space, reversed lockups |

**Accessibility:** Primary Peach on Cream Base = 3.2:1 (large text only). Use Charcoal on Cream for body copy (12.1:1). Peach on White = 2.9:1 — avoid for text.

| Email Signature | 180px wide | .png | Horizontal lockup |

### Print
| Asset | Spec | Notes |
|-------|------|-------|
| Hang Tag | 55×85mm | Mark front, wordmark back, uncoated stock |
| Woven Label | 15×40mm | Single-color (terracotta thread on cream) |
| Store Signage | Vector | Illuminated: peach LED halo; Non-lit: charcoal |
| Shopping Bag | 300×400mm | Cream paper, peach foil stamp mark |
| Tissue Paper | 500×750mm | Repeating mark pattern, 15% opacity peach |

### Motion
- **Entrance:** Mark draws in (1.2s ease-out) → wordmark fades up (0.4s delay)
- **Loop:** Subtle peach pulse on mark (3s cycle, 10% opacity shift)
- **Exit:** Wordmark fades → mark reverses draw (0.8s)

## 10. Handoff Notes for Designer

- All concepts built on 120×120 mark grid, 8px stroke base unit
- Gradients use 3-stop max for print reproducibility
- Peach accent `#C97B6B` is the *only* color allowed to touch Charcoal `#2D2D2D` directly
- No drop shadows, glows, or effects in master files
- Devanagari wordmark: "सिनाफाया" — match x-height, optical weight to Latin
- Test mark at 8mm physical (embroidery) before finalizing curves
